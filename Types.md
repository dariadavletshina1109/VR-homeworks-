Задание 1: подбор типов данных

- Количество жизней игрока → int (жизни всегда целые, 2.5 жизни не бывает)
- Скорость движения персонажа → float (скорость бывает дробной, например 3.5)
- Имя уровня → string (это текст)
- Координаты камеры в трёхмерном пространстве → три float (x, y, z); в Unity для этого есть тип Vector3
- Время загрузки сцены → float (секунды, обычно дробные, например 1.75)
